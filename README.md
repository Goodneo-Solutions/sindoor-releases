# sIndoor SDK releases

Prebuilt sIndoor SDK packages: indoor routes, tours and positioning on the device, and a navigation screen on sMap maps.
Documentation: https://open.superroute.ca/developer

- **Swift Package Manager** (iOS 15+, macOS 12+): add `https://github.com/Goodneo-Solutions/sindoor-releases`, products
  `SIndoor` and `SIndoorMap`.
- **Android** (Gradle): repository `https://goodneo-solutions.github.io/sindoor-releases/maven`, artifacts
  `ca.superroute:sindoor:<version>` and `ca.superroute:sindoor-map:<version>`.
- **npm**: `@superrouteca/sindoor`, `@superrouteca/sindoor-react`, `@superrouteca/sindoor-editor`,
  `@superrouteca/sindoor-react-native`.
- **pub.dev**: `sindoor`, `sindoor_map`.
